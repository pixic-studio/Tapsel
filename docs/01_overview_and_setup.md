# ۱. معرفی کلی پروژه و تنظیمات اولیه (Overview & Setup)

## ۱.۱ معرفی پروژه
این پروژه به منظور پیاده‌سازی و اعتبارسنجی شبکه تبلیغاتی **تپسل پلاس (Tapsell Plus SDK)** برای بازی‌ها و اپلیکیشن‌های ساخته شده با موتور **Godot 4** روی پلتفرم **اندروید (Android)** طراحی شده است.

در نسخه ۴ موتور گودو، سیستم افزونه‌های اندروید (Android Plugin) از معماری نوین v2 مبتنی بر ماژول‌های Gradle استفاده می‌کند. در این پروژه، کدهای بومی جاوا مستقیماً در قالب قالب ساخت بیلد اندروید گودو (`android/build`) کامپایل شده و ارتباط دوطرفه بین موتور گودو و SDK تپسل از طریق سینگلتون بومی و سیگنال‌ها برقرار شده است.

## ۱.۴ رفتار اختصاصی روی اندروید (Android Only)

با توجه به اینکه SDK تپسل بومی پلتفرم اندروید (`.aar`) است، در فایل [`main.gd`](file:///c:/Users/aa600/Desktop/test%20tapsel/test-tapsel/main.gd) شرط زیر قرار داده شده است:

```gdscript
is_android = (OS.get_name() == "Android")
if not is_android:
    update_status("توجه: تپسل فقط روی اندروید فعال می‌شود.", Color.ORANGE)
    set_buttons_enabled(false)
    return
```

این تدبیر مانع از آن می‌شود که در صورت اجرای بازی در محیط ادیتور گودو روی ویندوز، مک یا لینوکس، بازی با خطای `Engine.get_singleton(...) is null` کرش کند. دکمه‌ها غیرفعال شده و پیامی به کاربر نمایش داده می‌شود که خروجی را روی اندروید تست نماید.
